ドパ地図（子どもの端末用）

このフォルダの4つのファイルを、まとめて無料のWeb公開サービスに置くと、
そのURLを子どもの端末で開くだけで遊べます。

・index.html            アプリ本体（このファイル1つで動きます）
・apple-touch-icon.png  ホーム画面のアイコン
・icon-512.png          アイコン（Android用）
・manifest.json         ホーム画面に追加したときの設定

ホーム画面への追加（iPhone・iPad）
  Safariで開く → 共有ボタン → 「ホーム画面に追加」
ホーム画面から開くと、アドレスバーのないアプリの画面になり、記録も残りやすくなります。

記録（おぼえた・最高得点）はその端末の中だけに保存されます。
端末をまたいで共有はされません。

ドパドリル（gear_machine）の非公式 改造版です。個人・家庭での非営利利用にかぎります。
地図：地球地図日本（国土地理院）・Natural Earth をもとに簡略化。
